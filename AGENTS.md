# Project context

This project concerns grade 10 admissions in Ho Chi Minh City (TP.HCM).
The Can Tho admissions site is a design reference only. New content, school directories, addresses and synthetic import datasets must use TP.HCM context.
Do not relabel Can Tho schedules, quotas or results as TP.HCM data. Use verified TP.HCM sources or records published through the application, and show an empty state when these are unavailable.

See docs/project_context.md for the project scope.
